# Changelog

## v1.0.0 (2026-11-04)

- Improved link previews to show full titles (including YouTube links) and fixed fallback behavior for broken links.
- Links inside cards now open directly in your default system browser.
- Added support for importing boards in three different modes and exporting full documents.
- Hide specific project cards from global views and search results.
- Moved column controls to the view header, adding options to hide or restore columns, mark all cards as done, and archive all visible cards.
- Added a dedicated view to browse and restore archived cards.
- Introduced new keyboard shortcuts: switch projects (`g p`), create a task (`c`), and open the shortcut reference overlay (`?`).
